# dotfiles

Personal dotfiles for my daily Linux setup. Currently built around the Catppuccin Mocha color scheme, the Niri scrolling compositor, and Ghostty terminal.

Includes configuration for: Niri · Ghostty · Fish · Waybar · Fuzzel · Mako · MPV (uosc) · btop · bat · fastfetch · starship · wlogout · hyprlock

---

Many of the configurations in this repository are inspired by or borrowed from the work of others in the community. There are too many sources to credit individually, but I'm grateful to everyone who shares their dotfiles publicly.
